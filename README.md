# 🌟 Shinchan Student Portfolio Gallery

## 📌 About the Project

The **Shinchan Student Portfolio Gallery** is a fun and colorful website inspired by the characters from the Shinchan cartoon series.

The website displays character profiles in a gallery format. Each profile includes a character image, name, class or occupation, a short description, personality tags, and a link to view the individual portfolio.

This project was created as a beginner-level web development project using HTML and CSS.

## ✨ Features

- 🌈 Colorful cartoon-inspired design.
- 🖼️ Gallery featuring 8 Shinchan characters.
- 👤 Character names, descriptions, and profile images.
- 🏷️ Personality tags for each character.
- 🔗 Buttons linking to individual portfolio pages.
- 🎨 Different background colors for each character's image section.
- 🖱️ Hover effects on profile cards and buttons.
- 📱 Responsive layout for smaller screens.
- 🏫 Attractive header and footer.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used for styling, colors, grid layout, borders, shadows, hover effects, and responsive design.

**File descriptions:**

- `index.html` – Main page containing the character gallery.
- `styles.css` – Contains the design and styling of the website.
- Individual HTML files – Intended to contain the portfolio pages for each character.

*Note: The individual portfolio files must exist in the project folder for their links to work.*

## 🚀 How to Run the Project

1. Download or clone the project repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `styles.css` are in the same folder.
4. Open `index.html` in a web browser.
5. Click the **View Portfolio** buttons to explore individual character pages.

You can also install the Live Server extension in VS Code to preview the website while developing it.
